# Search Service

Search service for the
[Healthcare Microservices Platform](https://github.com/popelolole/healthcare-microservices-platform).

Provides search endpoints for patients, doctors, conditions and encounters.

## Tech

Java · Quarkus · Hibernate Panache · MySQL · OIDC · Docker · Kubernetes

## CI/CD

GitHub Actions builds the application, runs the tests and publishes a Docker image.
